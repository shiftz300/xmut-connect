# 管理模式变更说明

以当前 `main` 的 `8576e7a` 为开发起点。沿用已有 EasyConnect 认证、资源解析、代理、用户态协议栈和 AGPL-3.0 许可证。

- EasyConnect 的交互处理器新增可选的 context 接口，现有 CLI 输入处理器保持兼容。管理控制器为每次认证和短信挑战生成独立标识，并对提交、取消和超时做原子检查。
- 管理 HTTP 服务独立于 VPN 会话。控制器拥有会话和代理的清理顺序，允许复用合法会话重建隧道。原生会话、虚拟 IP、HTTP/DNS 保活继续运行。已知 SHUTDOWN 和明确的网关登录失效响应触发一次重新认证，并等待操作员提供验证码。
- 健康探针强制执行资源匹配和 VPN 路由。代理连接和监听器绑定到单次隧道的生命周期，可在新会话重新开启。
- 管理日志使用固定事件和错误码，WebUI 的 Bearer 令牌保存在页面内存。API、WebUI 和可选 Webhook 由标准库提供。
- 增加 Linux 安装、1Panel/Supervisor、systemd、Nginx 和 Shadowsocks 客户端范例。Linux 实例锁与监听端口共同防止重复启动，管理进程可由非 root 用户运行。
